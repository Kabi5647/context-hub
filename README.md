# Context Hub

Shared context for every AI model you use. Paste this repo (or a project folder / raw file URL) into another chat so models start with the same background — no paid APIs.

## How other AIs should use this

1. Read `CORE.md` first (who the owner is + defaults).
2. Open `projects/_index.md` and pick the project you are working on.
3. Read that project's `BRIEF.md` and `STATUS.md`.
4. Skim the latest file(s) in `handoffs/`.
5. Do the work in the right `parts/` file.
6. Update `STATUS.md`, then leave a new handoff in `handoffs/` named `YYYY-MM-DD-<model>.md`.

## Quick link pattern

- Whole hub: this repo URL
- One project: `projects/<slug>/`
- Always-on background: raw URL for `CORE.md`
- Starter instruction to paste: `prompt/load-context.md`
